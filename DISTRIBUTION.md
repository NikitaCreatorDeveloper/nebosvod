# Распространение PUBLIC

Выпуск `1.0.0-rc.3` распространяется как PUBLIC prerelease. Техническая готовность не заменяет проверку условий
Open-Meteo, RainViewer и OSM для предполагаемой аудитории и объёма использования.
Данные доступны без ключей; RainViewer free API не предназначен для высоконагруженной
коммерческой интеграции. См. THIRD_PARTY_NOTICES.md и официальные условия.
Публикация выполняется по разрешению владельца через отдельный docs-only workflow.
В Release входят подписанный APK, SHA256SUMS.txt и публичный сертификат подписи.
Kotlin source, AAB, приватный ключ, пароли и локальные настройки не публикуются.
SHA256SUMS.txt также содержит контрольную сумму локально собранного AAB; сам AAB не распространяется.
