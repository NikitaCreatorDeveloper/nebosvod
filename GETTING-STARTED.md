# Начало работы · PUBLIC

## Для пользователя

1. Откройте [релиз 1.0.0-rc.3](https://github.com/NikitaCreatorDeveloper/nebosvod/releases/tag/v1.0.0-rc.3).
2. Скачайте `Nebosvod-1.0.0-rc.3.apk`.
3. При желании сравните SHA-256 по инструкции в [INSTALLATION.md](INSTALLATION.md).
4. Установите APK стандартным Android installer.

API-ключи не нужны. Добавьте город или координаты; прогноз и ИКВ загрузятся из Open-Meteo.

Вкладка «Карта» использует OpenStreetMap и наблюдаемый радар осадков RainViewer. Вне радарного покрытия данные не имитируются. Слои облачности, температуры и ветра карты в PUBLIC-варианте отсутствуют.

Настройки единиц, темы, обновления, города, offline-кэш и виджет доступны в публичной сборке.

PUBLIC устанавливается как отдельное приложение с package `app.nebo.weather.public`; автоматического переноса данных из личных/dev-сборок нет.

## Доверие к установке

APK подписан publisher key, а release содержит SHA-256 и публичный сертификат. Возможное предупреждение Play Protect при sideload не означает отсутствие Android-подписи. Текущий статус регистрации разработчика и правильный путь для владельца описаны в [INSTALLATION.md](INSTALLATION.md).
